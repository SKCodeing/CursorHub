产品概述

CursorHub 是一款 Cursor 账号管理工具，核心解决以下问题：

🔄

无感换号

通过注入 Cursor 本体，在 AI 对话额度用尽时自动推送新 token，无需重启 Cursor。

📦

账号池管理

本地 SQLite 数据库存储多个账号，支持增删查、导入导出、批量刷新状态。

💾

备份恢复

一键备份 Cursor 的设置、快捷键、扩展、代码片段，随时还原。

🛡️

禁用自动更新

写入 update.mode=none，防止 Cursor 升级覆盖注入补丁。

⚠️
使用前提 CursorHub 需要 Cursor 安装在默认路径，且本机已正常安装 Cursor。首次启动后点击「刷新」按钮让工具自动检测路径。

安装与启动

下载 DMG 文件

下载 CursorHub-1.1.3-arm64.dmg，双击打开。

拖入 Applications

将 CursorHub.app 拖入 Applications 文件夹。

首次打开（绕过 Gatekeeper）

由于应用未经 Apple 公证，首次需要右键 → 打开，在弹出窗口点「打开」。之后可以正常双击启动。

点击刷新，初始化路径

首页点击右上角刷新图标，工具会自动检测 Cursor 安装路径和数据文件路径。两个绿色 ✓ 即为就绪。

💡
也可以通过命令行去掉隔离属性
xattr -cr /Applications/CursorHub.app

账号管理

「账号」Tab 是账号池的核心管理界面，支持以下操作：

➕

手动新增

点击「新增」按钮，填入邮箱和 accessToken（或 WorkosCursorSessionToken）即可添加。

📥

导入 JSON

支持导入 JSON 格式的账号文件，字段与导出格式一致，可批量导入。

📤

导出 JSON

将本地账号池导出为 JSON 文件，方便备份或迁移到其他设备。

🔁

批量刷新

点击「批量更新」，对所有有效 token 的账号重新拉取订阅状态和用量信息。

账号状态说明

状态说明
使用中当前 Cursor 正在使用的账号（绿色高亮行）
未使用从未被切换使用过
已使用用过但未检测到额度耗尽
已用尽触发过 quota 耗尽事件，自动换号会跳过此账号

切换账号

点击账号行的「使用」按钮，弹出切换确认框，可以选择：

选项说明
热切换（无感换号）通过 token server 推送，Cursor 不重启，对话不中断。需先开启无感换号注入。
重置机器码同时重置 machine-id，适合绑定机器的账号。
重启 Cursor关闭并重新启动 Cursor 让账号生效。
✅
最佳实践 开启无感换号后，优先使用热切换。不重启 Cursor 就能完成账号切换，用户体验最佳。

无感换号

无感换号是 CursorHub 的核心功能，通过向 Cursor 本体注入一段 JS patch，让 Cursor 在需要时主动从本工具的 token server 拉取新 token，整个过程无需重启。

开启步骤

点击「开启无感换号」

首页无感换号卡片中，点击绿色按钮。注入成功后状态变为「已注入」。

保持 CursorHub 在后台运行

CursorHub 充当本地 token server（端口 14620），Cursor 换号时会请求此服务。不能完全退出 CursorHub。

（可选）开启自动换号

开启「额度用尽时自动换号」后，Cursor 检测到 usage limit 会自动从账号池取下一个账号切换，无需人工干预。

⚠️
注意事项 自动换号可能中断正在进行的 Agent 任务。如不希望自动打断，保持关闭，需要时手动在账号列表点「使用」。

换号后不生效？

换号后需要等待 1-3 秒让 Cursor 内存生效，或者新建一个对话窗口再试。若仍提示额度不足，尝试关闭无感换号、重新登录账号后再开启。

🚫
Cursor 升级会导致注入失效 Cursor 每次更新都会覆盖被注入的文件。建议在首页开启「禁用 Cursor 更新」，或每次升级后重新点击「开启无感换号」。
6

禁用 Cursor 更新

开启后，工具会全面接管 Cursor 的更新机制，彻底屏蔽所有更新提示与弹窗，保护无感换号功能不被版本升级破坏。

状态说明
已开启Cursor 不会自动更新，所有更新弹窗均被屏蔽，补丁安全
已关闭Cursor 可自动更新，升级后需重新注入补丁
💡
建议 使用无感换号期间保持此开关开启。若需手动升级 Cursor，先关闭此开关，升级完成后再重新开启，并重新点击「开启无感换号」。

备份与恢复

CursorHub 支持备份 Cursor 的个人配置，包括：

  • 用户设置（settings.json）
  • 键盘快捷键（keybindings.json）
  • 已安装扩展列表
  • 代码片段（snippets）

备份

点击首页「备份设置」

选择备份文件的保存位置，工具会将上述配置打包导出。

恢复

点击首页「备份恢复」

选择之前导出的备份文件，工具会将配置还原并重启 Cursor。

⚠️
注意 恢复操作会覆盖当前 Cursor 的设置，请在恢复前确认备份文件来源正确。
8

定时采集

定时采集功能每秒检测 Cursor 当前登录账号（读取本地 storage.json 和活跃 token server），发现新账号时自动写入本地账号池（状态为「未使用」）。

适用场景

  • 在 Cursor 里手动登录了多个账号，想批量采集到账号池
  • 通过自动注册脚本注册了账号，想边注册边采集

点击「开始采集」

按钮变红，日志显示「已开启定时采集，每秒检测账号变化...」

在 Cursor 里切换账号

每次检测到新邮箱，CursorHub 自动将账号（含 token）存入账号池。

点击「停止采集」

结束后前往「账号」Tab 查看采集到的账号列表。

💡
采集到的账号初始状态均为「未使用」，不会影响已有的使用状态记录。
9

重置机器码

Cursor 使用 machineId、machineGuid 等标识符绑定设备。重置机器码会生成新的随机标识符，使 Cursor 认为是一台新设备，从而重置试用资格。

🚫
需要管理员权限 重置机器码需要写入系统级文件，操作时会弹出权限请求，请点击「允许」。

何时使用

  • 切换账号后 Cursor 仍提示设备已绑定
  • 注册新账号前，确保机器码是全新的
  • 配合「切换账号」使用，在账号管理页切换时勾选「重置机器码」选项

常见问题

打开应用提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」
右键点击 CursorHub.app → 点击「打开」→ 在弹出窗口点「打开」。或在终端执行：
xattr -cr /Applications/CursorHub.app
首页显示「未找到 Cursor 安装路径」
确认 Cursor 已安装到默认路径（macOS: /Applications/Cursor.app）。先打开 Cursor，再回到 CursorHub 点击刷新按钮重新检测。
无感换号注入后，热切换没有效果
1. 确认 CursorHub 没有完全退出（保持在后台）
2. 切换后等待 1-3 秒，或新开一个对话窗口
3. 如仍无效，尝试：关闭无感换号 → 重新开启 → 重新切换账号
升级 Cursor 后换号功能失效
Cursor 升级会覆盖注入的补丁。重新打开 CursorHub，点击「开启无感换号」重新注入即可。建议开启「禁用 Cursor 更新」防止自动升级。
账号池里的账号不见了
账号数据存储在本地 ~/Library/Application Support/CursorHub/cursor-hub-accounts.db。如果是从旧版本（FlyCursor）升级，工具会自动从旧路径迁移数据，无需手动操作。
切换账号后 Cursor 还是提示额度不足
该账号可能已经真正用尽（状态变为「已用尽」）。请在账号管理页选择一个「未使用」状态的账号，点击「使用」进行切换。
如何把 token 填入账号？
在 Cursor 浏览器端登录后，从 cookie 中提取 WorkosCursorSessionToken（格式为 user_xxx::eyJ...），或从 storage.json 中获取 cursorAuth/accessToken。填入账号管理的新增对话框中的 Token 字段。

使用建议

🎯
推荐工作流 开启无感换号 → 开启禁用更新 → 导入/采集多个账号 → 开启自动换号 → 正常使用 Cursor，额度到了自动切换，完全无感。
场景建议操作
日常使用开启无感换号 + 自动换号，保持 CursorHub 后台运行
账号快用完了在账号管理页批量刷新，确认有「未使用」账号可用
Cursor 需要更新先关闭「禁用更新」，更新完后重新开启并重新注入补丁
换新电脑导出账号池 JSON → 新电脑导入 → 重置机器码 → 切换账号
账号池快空了使用定时采集，配合其他账号来源批量补充账号
