# 关于页内容维护

关于页展示应用名、简介、外链、赞赏码和联系方式。改文案或换图后，重启 `npm run dev` 即可预览。

---

## 改哪里

| 要改的内容 | 文件 |
|---|---|
| 应用名称（关于页标题、首页环境信息） | `src/main/services/config.js` |
| 简介、链接、QQ、页脚文案 | `src/renderer/src/components/About.vue` |
| 赞赏码 / 交流群二维码 | `src/renderer/src/assets/donate/` |
| 应用图标（侧栏、关于页） | `src/renderer/src/assets/image/icon.png` |
| 版本号 | `package.json` 的 `version` |

---

## 1. 应用名称

文件：`src/main/services/config.js`

```js
appName: "CursorHub",
```

关于页会读这个字段。不要只改 `package.json` 的 `name`，界面不会跟着变。

---

## 2. 链接、QQ、简介

文件：`src/renderer/src/components/About.vue`

### 链接地址

在文件顶部的 `LINKS` 里改 URL：

```js
const LINKS = {
    github: "https://github.com/....../releases/latest",  // GitHub /「下载更新」按钮
    docs: "https://docs.qq.com/....",                     // 在线文档
    qqGroup: "https://qun.qq.com/....",                   // QQ 群邀请
    pan123: "https://www.123865.com/....",                // 123 云盘
    baidu: "https://pan.baidu.com/....",                  // 百度网盘
};
```

对应界面：

- **GitHub Releases** → `LINKS.github`
- **在线文档** → `LINKS.docs`
- **123 云盘 / 百度网盘** → `pan123` / `baidu`
- **QQ 交流群** → `LINKS.qqGroup`（点进去的链接）
- 「使用帮助」走本地 `docs/help.html`，不在 `LINKS` 里

GitHub 那一行的副标题（如 `liqiang-xxfy/fly-cursor-free`）、网盘提取码等，在模板里对应 `link-desc` 文字一起改。

### QQ 号

```js
const contactQQ = "807600577";   // 作者 QQ（赞赏说明、页脚）
const qqGroupNo = "569846057";  // 群号（仅展示）
```

群邀请链接仍改 `LINKS.qqGroup`。

### 简介

模板里这段：

```html
<p class="app-desc">
    Cursor 账号管理助手：本地账号库、无感换号与环境维护，让切换账号更省事。
</p>
```

## 3. 赞赏码 / 群二维码

目录：`src/renderer/src/assets/donate/`

| 文件名 | 界面标签 |
|---|---|
| `wechat.png` | 微信 |
| `alipay.png` | 支付宝 |
| `qq-group.jpg` | 交流群 |

**用同名文件覆盖即可，不用改代码。**

建议：

- 正方形、清晰、白底
- 微信 / 支付宝用 PNG
- 群码可以是 JPG 或 PNG（若改成 PNG，同时改 `About.vue` 里的 `import qqGroupQR from "..."`）

改完后刷新开发窗口；若没更新，硬刷新或重启 `npm run dev`。

---

## 4. 应用图标

当前界面用的是：

```
src/renderer/src/assets/image/icon.png
```

打包用的是：

```
build/icon.png
build/icon.icns
```

换图标时两处都换成同一套，避免侧栏 / 关于页和安装包图标不一致。

---

## 5. 版本号

改 `package.json`：

```json
"version": "1.1.3"
```

关于页的 `v1.1.3` 来自 Electron 的 `app.getVersion()`，跟 `package.json` 走。
